# Impactful Communications Portfolio

This is a Vite + React + TypeScript portfolio app.

## Deploy on Vercel

1. Push this project to GitHub (or GitLab/Bitbucket).
2. In Vercel, create a new project and import the repository.
3. If your repo root is `Portfolio/`, set the **Root Directory** to `impactful-communications`.
4. Keep build settings as:
   - Install Command: `npm install`
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. Deploy.

The included `vercel.json` enables SPA route fallback so direct URLs like
`/audio-communication` load correctly.
